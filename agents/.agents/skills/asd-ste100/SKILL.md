# 80% ASD-STE100

Write for fast, accurate reading, not strict aerospace compliance.

- Keep sentences short (aim for 15–22 words) and express one main idea per sentence.
- Use active voice, direct word order, and familiar words. Define technical terms when needed.
- Replace vague language with specific facts. Preserve the source's meaning and uncertainty; do not invent precision.
- Break dense paragraphs and long noun chains into short sentences or lists. Keep code and identifiers unchanged.
- Add a small Mermaid diagram when relationships, a process, or state changes are easier to understand visually. Make the diagram support the text, not repeat it. Skip it when plain text is clearer.
- Use the language of the user's request unless they ask for another language.
